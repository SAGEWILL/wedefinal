# Mabaso Family Bakery Website

A simple, responsive HTML, CSS, and JavaScript website for the Mabaso Family Bakery.

## Features Added

* **Interactive Mobile Navigation**: Toggle support for responsive navigation menus on smaller screens.
* **Form Validation & Error Handling**:
  * **Contact Form**: Validates required fields, checks proper email formatting, and provides inline feedback.
  * **Custom Orders Form**: Validates customer details, phone numbers, and automatically restricts pickup dates to enforce a minimum advance notice window.
* **Dynamic Notifications**: Built-in toast notification system providing visual feedback upon successful form submissions.
